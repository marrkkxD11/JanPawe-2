KREMÓWKOWY PAPIEŻ

1. Otwórz index.html w przeglądarce.
2. Strona używa kremowka.png jako tła.
3. Papież pojawia się co 30 sekund i znika po 7 sekundach.
4. Przycisk pozwala pokazać go od razu.
5. Zdjęcie papieża jest ładowane z Wikimedia Commons, więc przy pierwszym uruchomieniu potrzebny jest internet.

Aby zmienić czas, edytuj w index.html:
const INTERVAL=30;
Np. const INTERVAL=10; oznacza 10 sekund.
